怎么使用

左边是参考图，右边是当前 3D 场景。使用 1–7 切换工具。参考图可滚轮缩放，按住空格拖拽平移；选择「查看 / 选对象」时可拖动旋转场景、右键平移、滚轮缩放。

选择带相机位姿的参考图时，场景会切到对应拍摄机位。手动旋转后，可点「对齐参考视角」重新对齐；「叠图对比」方便检查轮廓。没有相机位姿的图片仍可手动对照。

在场景里点击「标注当前视角」，固定此刻的截图、视角、选中对象与版本。你可以在固定截图上画点、框、线、箭头、自由线或文字；新结果到来后旧标记仍对应原截图。

标记可以只出现在参考图上。需要表示两边对应时，给标记选择同一个编号即可。绑定原 Codex 任务后，反馈会送入该任务；使用普通 MCP 模式时，反馈先保存，待 MCP 工具读取后交回 Codex。页面会显示当前送达状态。
