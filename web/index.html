怎么使用

底部半透明会话框可点「收起会话」隐藏；标注完成后点右下角「展开会话」继续输入，草稿和标记会保留。聊天记录位于输入框上方，可独立收起；有新消息时入口会显示数量，查看旧消息时可点「回到最新」。按 Ctrl / ⌘ Enter 发送。

左边是参考图，右边是当前 3D 场景。使用 1–8 切换工具。会话收起时，Codex 正在处理会显示转圈状态；会话从右下角入口平滑展开，收起时缩回入口，保留草稿、滚动位置和自定义高度；系统开启减少动态效果时直接切换。左右拖动中间分隔线可调整参考图与场景宽度，双击恢复均分；窄屏仍上下排列。截图栏可点左侧小箭头收起或展开，收起后显示截图数量，截图和标记保留。工具栏的「物品 / 部件」决定在 GLB 中点击顶层物品还是具体节点；参考图可滚轮缩放，按住空格拖拽平移。选择「选择」时可拖动旋转场景、右键平移、滚轮缩放。

选择带相机位姿的参考图时，场景会切到对应拍摄机位。手动旋转后，可点「对齐」重新对齐；参考图默认叠在实时场景上，可将透明度调为 0% 隐藏。截图或开始标记时会保留当时的叠图参考与位置；标记画在叠图上方，仍可调整本张截图的透明度或开关。每张截图的设置独立保存，切换左侧参考图不会替换旧截图的叠图。发送时附带带标记的叠图对比、干净场景截图、参考原图及叠图参数。旧截图未保存叠图信息时，请回到 3D 新增截图。没有相机位姿的图片仍可手动对照。标为「同步」的缩略图会切换对应的视频机位，拖动进度条继续使用该机位。

选中点、框、线、箭头、自由画笔或文字工具后，可直接在右侧渲染图上圈画；系统自动固定当时的截图、视角、选中对象与版本，随提示一起发送。场景顶部的「3D 浏览 / 截图浏览」始终显示，高亮项表示当前模式。「3D 浏览」用于旋转、缩放和点选物体；「截图浏览」返回上一次操作的截图，不新增截图；没有截图时会提示「当前还没有截图」。进入后可选择标记或切换绘图工具继续圈画。「镜头」菜单提供聚焦和重置视角。选择「选择」工具可在截图中点击标记，按 Backspace 或 Delete 删除选中的标记；拖动到会话框即可引用，收起的会话会自动展开。标记按类型获得稳定名称，例如点1、点2，删除或撤销不会让其他标记改名。截图上方可点「隐藏名称 / 显示名称」切换文字标签，偏好刷新后保留；标记本身、文字注释、列表引用与发送的反馈名称保留。返回实时 3D 请点击「3D 浏览」；截图和标记保留，点击「＋ 截图」保存当前 3D 视角，旧图和标记继续保留，最多保留 8 张静态截图。点击场景左上角的缩略图，选择任意旧图继续标注。删除某张只移除它和自己的标记，可撤销。没有截图时列表隐藏，列表不会挤压 3D 画面。转动实时 3D 视角不会覆盖它，发送时会附带所有保留截图、各自标记及相机视角。

「橡皮擦」（快捷键 8）可点击或拖动擦除整条标记，松手生效；一次拖动可以擦多条，撤销一次会一起恢复。拖动中按 Esc 可取消。只擦当前参考图或所选截图中可见的标记，不修改原图；在实时 3D 中请先选择已保存的截图。橡皮擦旁的下拉按钮可调整大小（8–96 px），圆形光标表示擦除范围；大小、截图栏和左右比例会记住。方框内部的空白不会触发擦除；线段、箭头、文字、点和自由笔迹都可擦。

工具栏的「清空」会先弹出确认框，点击「确认清空」才移除本轮所有标记、截图和保留时刻；点击「取消」或按 Esc 保留内容，「撤销 / 重做」可回退或恢复新增、删除及清空标记；快捷键为 Ctrl / ⌘ Z 和 Ctrl / ⌘ Shift Z，也可用 Ctrl Y 重做。输入框保留文字自己的撤销。历史只保留在当前页面，刷新后重新开始；已发送的反馈不会改变。

标记可以只出现在参考图上。需要表示两边对应时，给标记选择同一个编号即可。在底部写一段完整提示，点击对象、选中节点或标记旁的「引用」把它插入光标处；一段话可以引用多个目标。打开「物体与标记」，点击「引用全部标记」即可一次插入全部标记，已有引用会跳过。动态标记的单条与全部引用都会带上机位、标记所在的片段帧号和时间，第一帧从 1 开始编号。可在顶部「任务」选择另一条 Codex 任务，或选择模型新建任务；切换后新反馈进入新任务，已提交反馈仍留在原任务。新任务不会继承旧对话。使用普通 MCP 模式时，反馈先保存，待 MCP 工具读取后交回 Codex。使用 MCP 事件模式时，反馈会保存在工作台；插件订阅后可接收视觉反馈事件。本页面不创建或切换 Codex 任务，订阅状态可在「记录」中查看。

动态参考可用「添加机位视频 / 帧序列」导入；多选视频时，每个视频添加为独立机位，图片序列每次添加一个机位，已有机位和标记保留。最多 8 个机位，每个最多 600 帧。图片按文件名自然排序，以填写的帧率播放。视频由服务器用 FFmpeg 采样为参考帧。机位与动画 GLB 共用时间轴；通过左侧「机位」切换可保持当前时间，并按对应参考相机自动对齐。采样帧率不同时使用最接近当前时间的参考帧；较短机位在末尾保留最后一帧。未提供相机位姿的机位可手动对照。同一条提示可引用不同机位的标记，每个保留自己的截图和相机。多段 GLB 动画可选择具体动作。圈画时自动暂停并保留该时刻，最多保留 8 个时刻。可选择当前帧、时间区间或整个片段作为反馈范围。时间区间表达你的意图，标记仍只显示在各自帧上。

capsule 人体重建 skill 导入二维关键点后，「物体与标记」会显示「人体参考」。结果按机位、帧号与时间叠在对应参考图上，点击「引用人体」可把当前来源帧的关键点和骨架图加入提示，也可以下载完整 JSON。默认只显示当前帧最新的一份二维结果；没有二维结果时显示最新投影。结果旁的「显示 / 隐藏」可查看单份历史结果，「最新结果」恢复自动选择，「隐藏全部」关闭叠加。手动选择会保留，后续导入不会抢走。多人、遮挡或低置信度时请对照原图核对；各机位的二维结果不自动确认跨机位身份或生成三维姿态。从三维人体投影出的关键点会标为「三维投影参考」，与独立二维观测分别展示和引用。

显示「等待自动重试」时无需重复点击发送。「送达待核实」表示系统无法判断目标任务是否收到；先在目标任务中核对，确认未收到后再重试。事件投递失败后自动重试已停止；无活动订阅时反馈仍保存在工作台。检查插件连接，必要时让插件调用 workspace_get_feedback 按反馈 ID 读取图文证据。点击发送即可提交当前保留的截图和标记，旧截图无需再确认；场景更新不会中断投递，模型会收到原截图版本和投递时的当前版本。点击发送会保存当前截图、标记和提示，旧截图无需再确认；有插件订阅时会发出 MCP 事件。事件送达只表示插件接收端确认收到，不表示 Codex 已开始或完成执行。刷新会保留未发送的截图，不会把旧标记改写到新场景；需要重新圈画时可点「清空」，并可撤销恢复。服务器确认保存反馈后，本轮提示、全部标记、固定截图、保留时刻和物体/节点选择会自动清空，并回到实时 3D；已发送的图文证据仍保存在「记录」中。新结果到达时不会清除下一轮已开始的草稿。保存失败或结果未确认时，草稿保留；需要人工处理的反馈会显示在会话输入框上方，可在那里确认或重试。

在提示中输入 @ 可按名称、编号、ID 或类型搜索物体、部件、标记、当前图片、保存图片、当前帧人体结果及手部修正；方向键选择，Enter 插入，Esc 关闭，也可直接点击。菜单开启时 Ctrl / ⌘ Enter 选择引用，不发送。图片在选中或拖入时固定原图、标记和来源；后续改变视角或帧不会改写它。

待确认操作显示在会话输入框上方，收起记录也可处理；收起整个会话时显示「! 待确认」，点击后直接定位到卡片。执行时仍显示转圈。3D 浏览：左拖旋转、右拖沿屏幕平移、滚轮缩放；双击物体或选中后按 F 聚焦。右上角可切换六个方向、斜视或全景；镜头菜单提供自由旋转与回正。已有截图和标记保持原视角。
