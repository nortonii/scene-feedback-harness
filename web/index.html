02 / 发给 Astra

把你看到的告诉它

无需写坐标或操作命令。对象、视角和图片会随反馈一并发送。

已选对象 可选
未选对象也能提交。比如：参考图里缺了一个东西。
保留的标记 0
你画的点、框、线和文字会显示在这里。

每次会发送当前可见的全部标记、原图、场景视角和你的话。标记会保留；不想重复发送可删除或清空。

怎么使用

左边是参考图，右边是当前 3D 场景。使用 1–6 切换工具。选择「查看 / 选对象」时可拖动旋转场景，右键拖动平移，滚轮缩放；点击对象会自动记录它的 ID。

在任一侧画点、框、线、箭头或文字。标记可以只出现在参考图上。需要表示两边对应时，给标记选择同一个编号即可。

叠图仅帮你肉眼比较，未自动对齐相机。提交时请告诉 Astra 你想改变什么。
