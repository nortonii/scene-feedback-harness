怎么使用

先看图 → 标记差异 → 写修改要求 → 发送。记录与本次反馈可分别展开；拖动输入框或反馈详情顶部的小横条调整高度，双击恢复默认。会话顶部「本次反馈」可展开查看保留的截图、视频时刻和额外引用；发送包含本轮所有保留证据，引用只是指出具体目标。提交成功后，聊天消息下方可以重新查看原图、标注图和叠图对比。

底部半透明会话框可点「收起会话」隐藏；标注完成后点右下角「展开会话」继续输入，草稿和标记会保留。聊天记录位于输入框上方，可独立收起；有新消息时入口会显示数量，查看旧消息时可点「回到最新」。按 Ctrl / ⌘ Enter 发送。

对照模式左边是参考图，右边是当前 3D 场景。左上角图标打开工作台侧栏，可切换／新建场景、调整布局与日夜模式、查看任务、执行记录和帮助；子页面通过「返回场景」回到场景列表。点击侧栏外或按 Esc 收起，输入内容和滚动位置保留。参考区顶部导入素材，图片右下角提供缩放、适合窗口和标注。图片引用统一放在会话输入框左下角「＋」：可引用当前参考图／视频帧、当前场景画面／截图，或从已保存截图中选择；引用旧图保留其视角、标记和叠图，不跳转当前画面。正文用【图1】【点1】【柜子】等短名称引用，完整来源放在输入框内的卡片详情。同名的不同来源会加编号区分；图片卡片可预览，其他卡片可查看完整名称，× 只移除引用。删除短名称会整处删除，可撤销恢复。鼠标移入参考图片自动显示参考标注工具，移到工具栏继续操作时保持显示，离开图片与工具栏后收回；触屏轻点图片或键盘聚焦图片也可打开。实时 3D 点击右侧「标注」展开场景工具，进入截图时自动展开截图工具；仅打开面板、选择工具或打开参考浮窗不会生成截图。参考与场景分别记住工具：在参考图画点或擦除时，右侧实时 3D 仍可正常旋转。浮栏跟随当前操作的图片，可单独收起；常用工具包括选择、点、框、线和橡皮擦，「更多」里是箭头、文字、自由画笔和对应编号。也可用 1–8 切换工具。会话收起时，Codex 正在处理会显示转圈状态；会话从右下角入口平滑展开，收起时缩回入口，保留草稿、滚动位置和自定义高度；系统开启减少动态效果时直接切换。左右拖动中间分隔线可调整参考图与场景宽度，双击恢复均分；窄屏仍上下排列。截图栏可点右端固定的小箭头收起或展开，缩略图向左展开，收起后显示截图数量，截图和标记保留。场景顶部的物体选择菜单用「物体 / 部件」决定在 GLB 中点击整件物体还是具体节点；参考图可滚轮缩放，按住空格拖拽平移。实时 3D 中选择「选择」时可拖动旋转场景、右键平移、滚轮缩放，并点选物体或部件。

选择带相机位姿的参考图时，场景会切到对应拍摄机位。场景顶部「叠图」菜单统一提供叠加开关、透明度、常用档位和「对齐」。手动旋转后，可在这里重新对齐；将透明度调为 0% 也可隐藏叠图。截图或开始标记时会保留当时的叠图参考与位置；标记画在叠图上方，仍可调整本张截图的透明度或开关。每张截图的设置独立保存，切换左侧参考图不会替换旧截图的叠图。发送时附带带标记的叠图对比、干净场景截图、参考原图及叠图参数。旧截图未保存叠图信息时，请回到 3D 新增截图。没有相机位姿的图片仍可手动对照。标为「同步」的缩略图会切换对应的视频机位，拖动进度条继续使用该机位。

实时 3D 中可使用右侧的点、框、线、箭头、自由画笔和文字工具；首次真正点击或拖动画图时，系统自动保存当时的截图、相机、选中对象与版本，并在该截图上完成标注，随提示一起发送。仅打开面板或选择工具不会生成空截图。已固定截图上的后续笔画留在同一张图；返回实时 3D 后再次开始绘制会保存新截图，即使没有移动相机，旧图和标记仍保留。右侧顶部用同一排大卡片切换视图：第一格「3D」始终保留，用于旋转、缩放和点选物体；后面的截图按创建顺序排列，点击任意截图即可查看并标注，高亮卡片表示当前画面。右侧工具栏直接调整透明度与地面方向，「对齐」恢复参考拍摄机位；双击物体或按 F 聚焦。选择「选择」工具可在截图中点击标记，按 Backspace 或 Delete 删除选中的标记；拖动到会话框即可引用，收起的会话会自动展开。标记按类型获得稳定名称，例如点1、点2，删除或撤销不会让其他标记改名。截图的标注浮栏中可点「隐藏名称 / 显示名称」切换文字标签，偏好刷新后保留；标记本身、文字注释、列表引用与发送的反馈名称保留。返回实时 3D 请点击卡片栏第一格；截图和标记保留；调整实时 3D 视角后再次绘图会自动保存新图，旧图和标记继续保留。也可点击「截图」主动保存当前视角，最多保留 8 张静态截图。点击右侧顶部的截图卡片，选择任意旧图继续标注。删除某张只移除它和自己的标记，可撤销。没有截图时卡片栏仍保留实时 3D 入口；多张截图可横向滚动。转动实时 3D 视角不会覆盖它，发送时会附带所有保留截图、各自标记及相机视角。

「橡皮擦」（快捷键 8）可点击或拖动擦除整条标记，松手生效；一次拖动可以擦多条，撤销一次会一起恢复。拖动中按 Esc 可取消。只擦当前参考图或所选截图中可见的标记，不修改原图；在实时 3D 中请先选择已保存的截图。橡皮擦旁的下拉按钮可调整大小（8–96 px），圆形光标表示擦除范围；大小、截图栏和左右比例会记住。方框内部的空白不会触发擦除；线段、箭头、文字、点和自由笔迹都可擦。

标注浮栏「清除本图」只清除当前参考图或当前截图上的标记，保留图片与其他标记；顶栏「⋯ → 清空本轮图片与标记」才会移除整轮截图、时刻和标记。两者都会显示具体范围和数量，确认后执行；点击「取消」或按 Esc 保留内容，「撤销 / 重做」可回退或恢复新增、删除及清空标记；快捷键为 Ctrl / ⌘ Z 和 Ctrl / ⌘ Shift Z，也可用 Ctrl Y 重做。输入框保留文字自己的撤销。历史只保留在当前页面，刷新后重新开始；已发送的反馈不会改变。

标记可以只出现在参考图上。需要表示两边对应时，给标记选择同一个编号即可。在底部写一段完整提示，点击对象、选中节点或标记旁的「引用」把它插入光标处；一段话可以引用多个目标。点击场景工具栏的「清单」（旁边显示标记数量），再点「引用全部标记」即可一次插入全部标记，已有引用会跳过。动态标记的机位、帧号和时间保留在引用详情与反馈中，正文只显示标记短名称；第一帧从 1 开始编号。可在左侧栏的任务入口选择另一条 Codex 任务，或选择模型新建任务；切换后新反馈进入新任务，已提交反馈仍留在原任务。新任务不会继承旧对话。使用普通 MCP 模式时，反馈先保存，待 MCP 工具读取后交回 Codex。使用 MCP 事件模式时，反馈会保存在工作台；插件订阅后可接收视觉反馈事件。本页面不创建或切换 Codex 任务，订阅状态可在「侧栏 → 执行记录」中查看。

静态截图与视频保留时刻统一接在实时 3D 卡片后，按创建顺序排列并使用场景截图封面。封面默认 112×63，鼠标悬停或键盘焦点可见时在原位平滑展开为 160×90，尊重系统减少动态效果设置；触屏保持紧凑尺寸，可直接点击。卡片显示稳定截图名称；带时间的截图仅显示精确到毫秒的单个时间戳，例如 00:09.900，不附时间区间。悬停或键盘聚焦卡片不会打开悬浮预览弹窗。进度条下方的小刻度定位当前机位已保存的截图，同一时刻有多个视角时，点击刻度可打开选择列表。点击视频卡片会暂停并恢复保存的机位与时间；之后播放、逐帧或拖动视频只浏览参考，右侧固定截图与原标记保持不变，点击「3D」才返回实时场景。标注另一参考帧会保留该时刻的证据，不覆盖右侧正在查看的旧图。静态截图和动态时刻仍各最多 8 张，单独删除可撤销；删除不会改写其他截图的编号或来源。

动态参考可用「添加机位视频 / 帧序列」导入；多选视频时，每个视频添加为独立机位，图片序列每次添加一个机位，已有机位和标记保留。最多 8 个机位，每个最多 600 帧。图片按文件名自然排序，以填写的帧率播放。视频由服务器用 FFmpeg 采样为参考帧。机位与动画 GLB 共用时间轴；通过左侧「机位」切换可保持当前时间，并按对应参考相机自动对齐。采样帧率不同时使用最接近当前时间的参考帧；较短机位在末尾保留最后一帧。未提供相机位姿的机位可手动对照。同一条提示可引用不同机位的标记，每个保留自己的截图和相机。多段 GLB 动画可选择具体动作。圈画时自动暂停并保留该时刻，最多保留 8 个时刻。参考顶部显示视频名与帧号，底部「视频选项」菜单提供片段信息、保留此刻与动画动作。修改时段直接写在提示中：输入 /，自动列出当前参考帧、冻结场景截图、本轮标记与保留时刻，以及「本轮标记时段」和「整个片段」。可按机位、帧号、秒数或标记名搜索，用方向键选择、Enter 插入、Esc 关闭；菜单打开时 Ctrl / ⌘ Enter 只选择时间。场景时间和参考采样时间不同时会分别注明，时间按片段起点计算；插入的是可读文字，不跳转画面或改变标记。新反馈没有额外的默认范围。

capsule 人体重建 skill 导入二维关键点后，「物体与标记」会显示「人体参考」。结果按机位、帧号与时间叠在对应参考图上，点击「引用人体」可把当前来源帧的关键点和骨架图加入提示，也可以下载完整 JSON。默认只显示当前帧最新的一份二维结果；没有二维结果时显示最新投影。结果旁的「显示 / 隐藏」可查看单份历史结果，「最新结果」恢复自动选择，「隐藏全部」关闭叠加。手动选择会保留，后续导入不会抢走。多人、遮挡或低置信度时请对照原图核对；各机位的二维结果不自动确认跨机位身份或生成三维姿态。从三维人体投影出的关键点会标为「三维投影参考」，与独立二维观测分别展示和引用。

显示「等待自动重试」时无需重复点击发送。「送达待核实」表示系统无法判断目标任务是否收到；先在目标任务中核对，确认未收到后再重试。事件投递失败后自动重试已停止；无活动订阅时反馈仍保存在工作台。检查插件连接，必要时让插件调用 workspace_get_feedback 按反馈 ID 读取图文证据。点击发送即可提交当前保留的截图和标记，旧截图无需再确认；场景更新不会中断投递，模型会收到原截图版本和投递时的当前版本。点击发送会保存当前截图、标记和提示，旧截图无需再确认；有插件订阅时会发出 MCP 事件。事件送达只表示插件接收端确认收到，不表示 Codex 已开始或完成执行。刷新会保留未发送的截图，不会把旧标记改写到新场景；需要重新圈画时可点「清除本图」，并可撤销恢复。服务器确认保存反馈后，本轮提示、全部标记、固定截图、保留时刻和物体/节点选择会自动清空，并回到实时 3D；已发送的图文证据可从聊天消息下方「查看图片与标记」重新打开，或在「侧栏 → 执行记录」查看事件。新结果到达时不会清除下一轮已开始的草稿。保存失败或结果未确认时，草稿保留；需要人工处理的反馈会显示在会话输入框上方，可在那里确认或重试。

在提示中输入 @ 可按名称、编号、ID 或类型搜索当前选中的物体或部件，以及本轮全部未发送标记；未选物体且没有标记时会提示「先选中物体或添加标记」。跨机位、帧和截图的标记仍可搜索。方向键选择，Enter 插入，Esc 关闭，也可直接点击。菜单开启时 Ctrl / ⌘ Enter 选择引用，不发送。图片通过输入框左下角「＋」添加；添加时固定原图、标记和来源，后续改变视角或帧不会改写它。人体参考及手部修正通过专用入口引用。

待确认操作显示在会话输入框上方，收起记录也可处理；收起整个会话时显示「! 待确认」，点击后直接定位到卡片。执行时仍显示转圈。右侧工具栏直接显示透明度拖条、地面方向和对齐。透明度 0% 隐藏叠图，向右拖动恢复；截图上的设置只影响该图。左拖旋转、右拖沿屏幕平移、滚轮缩放；双击物体或选中后按 F 聚焦。地面方向按场景记住；「对齐」恢复当前参考图的拍摄机位，无相机位姿时不可用。已有截图和标记保持原视角。侧栏中的「沉浸」让场景铺满应用，「对照」返回双栏；切换布局和日夜模式后侧栏保持打开；常用场景操作浮在右上角，最右侧箭头可收起整条工具栏，再点原位箭头展开；浏览器记住选择，对照模式始终显示工具栏。「参考」打开左侧浮窗。参考浮窗可拖动标题栏移动，拖四边或四角调整大小，标题旁的复位图标恢复默认位置和尺寸；位置与尺寸按浏览器保存，切回对照不影响双栏。聚焦标题栏后可用方向键移动，聚焦右下角缩放柄后可用方向键调大小。月亮／太阳切换日夜模式。
